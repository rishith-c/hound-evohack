Product description

General Description

The HD 1080P USB CMOS board camera module(model: ELP-USBFHD01M serials)

is ideal for many applications like security systems, portable video system,

video phones, industrial machine monitoring and toys.

The USB camera module are ideal for equipment manufacturers, experimenters and hobbyists.

Parameters

Optional models ELP-USBFHD01M-L28(2.8mm lens)

Sensor:1/3" CMOS OV2710

Lens size:200W, 2.0megapixel, 1920(H)x1080(V)pixels

Max. Resolution:1920X1080

Picture format: MJPEG

USB Protocal: USB2.0 HS/FS, USB1.1 FS

Support free driver: USB Video Class(UVC)1.1

Frame rate:

MJPEG 30 fps @ 1920 (H) x1080 (V)
MJPEG 60 fps @ 1280 (H) x 720 (V)

Adjustable parameters: Brightness/Contrast/Color saturation /Definition/Gamma/WB

Auto exposure AEC: Support

Auto white blance AEB: Support

voltage: DC 5V

current:150mA

work temperature:DEGREES(-20~70)

Why we choose MJPEG USB camera ELP-USBFHD01M-L28?

Choose “MJPEG” final purpose is to reduce data stream, improve the video frame,

so that the video will more smooth and occupy less bandwidth.

Such as 1megapixel common camera,YUV format only have 10fps，while MJPEG usb camera can up to 30fps.

Most Linux USB port device is USB1.1, becuase bandwidth limited, can not receive YUV data stream,

so that need to choose the MJPEG data stream.

Common USB PC camera do not have MJPEG DSP, even those support MJPEG but can not work with USB 1.1 yet.

ELP-USBFHD01M-L28 usb camera module can use in where？

It can use in”any,all,whole...“ Linux CPU operating system

which come with USB Host port,including USB1.1 and USB2.0
