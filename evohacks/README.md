# HOUND at EvoHacks 2

## Made during EvoHacks 2
- `evohacks/console/`: rescue-team operator console concept. It has a satellite map, a simulated earthquake shake field and damage zones, a route planner with Plan Route and operator approval before the robot moves, and sensor panels. **Every reading in it is simulated, and it is not connected to the rover yet.** Open `index.html` in a browser (it needs internet for the map tiles).
- `evohacks/screens/console.png`: screenshot of the console.
- A new shot in the demo video (2:51) that shows the console.
